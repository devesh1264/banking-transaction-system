Backend Ledger API

● Service Online

A secure banking transaction backend built with Node.js, Express, MongoDB and JWT Authentication.

Features

  • Secure User Authentication
  • JWT & Cookie Based Authorization
  • Create and Manage Bank Accounts
  • Money Transfer Between Accounts
  • Transaction History
  • MongoDB Database
  • RESTful APIs
  • Production Deployment on Render

Tech Stack

Node.js Express MongoDB Mongoose JWT Render

Available APIs

Method Endpoint
POST /api/auth/register
POST /api/auth/login
POST /api/accounts
GET /api/accounts
POST /api/transactions
GET /api/transactions
